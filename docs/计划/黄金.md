# 黄金白银全景 · 计划（2026-10-23，Fable 5.1 起草，待 Opus 5.5 实施、Fable 5.1 验收）

用户要一套**每天能用的黄金分析框架**，要求：因素会变，框架要分得清"现在谁在定价"；要看全球（伦敦、纽约、上海），不只看一个市场；白银一起看；用客观指标代替感觉；既识别恐慌也识别过热。方法沿用科技看板（`CLAUDE.md` 的原则 1–7 全部适用：不拟合、先登记再检验、刻度用整数和惯例、不用未来数据、均线只展示）。

## 一、核心想法

黄金的驱动因素会轮换（2001–2011 美元和债务贬值，2013–2021 实际利率，2022 至今央行买盘和财政担忧），所以框架分两半：

- **会变的一半——谁在定价**：每天量黄金最近 60 天和哪个宏观变量同步，只作描述，告诉用户当下该盯哪条线。
- **不变的一半——人群行为**：仓位挤不挤、有没有人恐慌卖出、实物买家在不在。这部分和科技看板同构，用对照格、清单、温度来衡量。

黄金和股票不同的地方，框架里要专门处理：
1. 黄金波动率（GVZ）在急涨时也会升。所以"GVZ 升 + 价格跌"才算恐慌，"GVZ 升 + 价格涨"算过热。
2. 黄金期权常常认购比认沽贵，偏度刻度要用黄金自己的历史，不照搬 SKEW。
3. 黄金趋势比股票持久。过热只用来减仓和不追，不做空。
4. 大牛市里真正的投降少。"等恐慌出清再买"要改成"等拥挤度退潮再买"。
5. 情绪极端在黄金上标顶比标底准，检验时分开看。

## 三、衡量框架（登记在 `gold/gold_engine.py`，先登记再检验）

### 1. 谁在定价（`driver()`，只作描述）

黄金日收益和下面每个变量的 60 日滚动相关（用当天以前的数据）：实际利率（`DFII10` 日变化，取负）、美元（`DX-Y.NYB`）、标普、通胀预期（`T10YIE` 日变化）、比特币、原油。相关最强的那个写成"最近 60 天黄金主要跟着 ×× 走"，和 20 天前比有没有换。另给"各币种金价"：美元、欧元、日元、人民币、韩元、印度卢比计价的 20 日涨跌，几种货币都在涨就写"黄金自己强"，只有美元计价在涨写"主要是美元弱"。

### 2. 价格位置（`pos`，同科技看板）

回撤 ÷ 长期年化波动：重伤 ≤ −1.2、回调 ≤ −0.6、延伸（离 200 日线 ≥ 1 倍年化波动）、正常。`px_features()` 直接复用。

### 3. 四个温度（各 0–100，`GAUGES`，分开显示）

刻度全部用整数或惯例，"起点 → 满格"写在登记表里。分位一律按全部历史、只用当天以前（`exp_pct()`）。

**拥挤度**（标顶用；黄金情绪分的"热"端）
| 项 | 原始值 | 起点 → 满格 |
|---|---|---|
| 期货仓位 | 管理基金净多 ÷ 未平仓量，历史分位 | 50% → 90% |
| ETF 流入 | GLD 吨数 20 日变化 | 0 → +5% |
| 矿业股跑赢 | GDX÷GLD 20 日相对涨幅 ÷ GDX 长期日波动 × √20（Z） | 0 → +2 |
| 白银跑赢 | 白银÷黄金 20 日相对涨幅的 Z | 0 → +2 |
| 杠杆多空 | NUGT÷DUST 成交量 10 日均的历史分位（2010 前用 UGL÷GLL） | 50% → 90% |
| 价涨波动也涨 | 离高点 3% 以内 × (GVZ ÷ 20 日最低 − 1) | 0 → 0.3 |
| 延伸 | 离 200 日线 ÷ 长期年化波动 | 0 → 2 |

**恐慌**（标底用；"冷"端）
| 项 | 原始值 | 起点 → 满格 |
|---|---|---|
| 急跌 | 20 日 Z 分数（取负） | 0 → 2 |
| GVZ 水平 | GVZ（配合价格在 20 日低点附近，否则不算） | 20 → 40 |
| GVZ 跳升 | GVZ ÷ 50 日均（同上，只在价格下跌时） | 1 → 1.5 |
| ETF 流出 | GLD 吨数 20 日变化（取负） | 0 → 5% |
| 仓位出清 | 管理基金净多分位（取反） | 50% → 10% |
| 矿业股急跌 | GDX 20 日 Z（取负） | 0 → 2 |
| 期权买保险 | GLD 认沽/认购比 10 日均的历史分位（自己攒的 `gold_options_history.csv`，不够一年时不算） | 50% → 90% |

**实物需求**（只作描述，不进情绪分）
| 项 | 原始值 | 起点 → 满格 |
|---|---|---|
| 上海溢价 | Au99.99 × 31.1035 ÷ 美元兑人民币 − 纽约期货，美元/盎司 | 0 → 30 |
| 上海成交 | Au99.99 + Au(T+D) 成交量 ÷ 50 日均 | 1 → 2 |
| 上期所持仓 | au 全部合约持仓 20 日变化 | 0 → +10% |
| 中国 ETF | 518880 成交量 ÷ 50 日均 | 1 → 2 |
| 央行 | 人民银行最近一个月增持吨数（月更） | 0 → 20 吨 |
| 期货贴水 | 最近两个活跃月份年化价差 − 2 年期美债（为负 = 贴水，实物紧） | 0 → −2 个百分点 |

**宏观顺风**（只作描述，不进情绪分）
| 项 | 原始值 | 起点 → 满格 |
|---|---|---|
| 实际利率 | `DFII10` 20 日变化（下行为顺风） | 0 → −50bp |
| 美元 | `DX-Y.NYB` 20 日涨跌（下跌为顺风） | 0 → −3% |
| 降息预期 | `DGS2` 20 日变化 | 0 → −50bp |
| 通胀预期 | `T10YIE` 20 日变化 | 0 → +30bp |

**黄金情绪分** = 拥挤度 − 恐慌，−100 到 +100，分档沿用 `SCORE_BANDS`。只作描述。合理区间照 `score_range()` 的做法重做。实物需求和宏观顺风是驱动因素，不是人群行为，所以不进分数，分开显示。

### 4. 对照格和清单

- 对照格：价格位置（延伸 / 正常 / 回调 / 重伤）× 拥挤度档（低 < 30 / 中 / 高 ≥ 70）。每格给历史上之后 60 天中位数和"同样回撤深度"的对照。
- **拥挤清单**（整数阈值，标顶）：净多分位 ≥ 90%；GLD 20 日流入 ≥ 3%；矿业股 20 日跑赢 Z ≥ 1；白银 20 日跑赢 Z ≥ 1；杠杆多空分位 ≥ 90%；价涨波动也涨；离 200 日线 ≥ 2 倍年化波动。
- **恐慌清单**（标底）：20 日 Z ≤ −2；GVZ ≥ 30 且价格在 20 日低点附近；GVZ ≥ 50 日均 1.4 倍且价格下跌；GLD 20 日流出 ≥ 3%；净多分位 ≤ 20%；GDX 20 日 Z ≤ −2。
- **拥挤退潮**（`t_cool`，买点候选，四条同时）：过去 60 天拥挤清单亮过 ≥ 3 条；净多分位从 ≥ 80% 回到 ≤ 50%；价格仍在 200 日线上方；价格回到 50 日线 3% 以内。
- **主线切换**：黄金和实际利率的 60 日相关由负转正或由正转负，标在 K 线上。

### 5. 先登记再检验的规则（`SPEC`、`COMBOS`，由 `gold/research_gold.py` 检验）

| 编号 | 规则 | 预期 | 检验样本 |
|---|---|---|---|
| G1 | 涨过头：延伸 ≥ 2 且净多分位 ≥ 90% 且价涨波动也涨 | 之后 60 天比任意日差 | 黄金；预计命中 2008-03、2011-09、2020-08、2024-10、2025-04 附近 |
| G2 | 拥挤退潮（四条） | 之后 60 天比任意日好 | 黄金 |
| G3 | 投降：重伤或回调 × 恐慌清单 ≥ 3 条 | 之后 60 天比同深度好 | 黄金；预计 2008-10、2013-06、2015-12、2018-08、2022-09 |
| G4 | 跌了没人慌：回调或重伤 × 恐慌 0 条 | 之后更差 | 黄金 |
| G5 | 主线切换后 60 天 | 只作描述 | 黄金 |
| GM1 | GVZ → 之后 21 天实际波动（白银用 VXSLV） | 能衡量幅度 | 黄金、白银 |
| GM2 | 200 日线下方 → 60 天内再跌 0.5 倍长期波动 | 能衡量风险 | 黄金、白银、GDX、SIL、铂、铜、原油、比特币、各币种金价 |

## 四、看板（`gold/gold_template.html`，照科技看板第六轮的结构和样式）

**第一屏**
1. 黄金情绪分：大数字、五档色条、合理区间、白话、一年走势。
2. 今天该知道的四件事：接下来可能波动多大（GVZ 给的 21 天预期范围，黄金、白银、GDX 各一个）；下跌风险（200 日线状态 + 历史再跌比例）；现在谁在定价（主线 + 各币种）；情绪走到哪一步（对照格那一格）。
3. 四个温度卡：拥挤度、恐慌、实物需求、宏观顺风，各带一年走势和分项条。
4. 三地价格一行：纽约期货、上海 Au99.99 折美元、上海溢价（有 LBMA 时加伦敦）；白银同一行。

**K 线**（复用科技看板的画图代码）
- 品种：黄金期货（默认）、白银、GDX、SLV、518880、金价（人民币）、金价（欧元）、金价（日元）、白银÷黄金、GDX÷GLD。
- 副图：情绪分（默认）、四个温度、GVZ 与实际波动、管理基金净多分位、GLD 吨数、上海溢价、实际利率、美元、RSI、清单条数。
- 标签：涨过头、退潮、投降、主线切换；极热 / 极冷 / 急升 / 急冷（情绪分 ±60 和 10 日最快 2%）。
- 最新一根右边 GVZ 预期范围。可画线、滚动条、摆动结构照旧。

**折叠块**
- 对照格和清单；每日一览（最近 20 / 60 天）；期权怎么看（GLD、SLV、GDX 五问）；白银（恐慌与拥挤的白银版：VXSLV、白银净多、SLV 盎司、AGQ÷ZSL、Ag(T+D) 溢价、比值）；全球视角（各币种金价表、上海和上期所成交持仓、央行月表、世界黄金协会链接）；矿业股参与度；历次对照；说明和指标词典（每个指标三句话：是什么、代表什么情绪、有什么用）。
- 默认白色，页头按钮切深色，记在 `localStorage` 的 `gs-theme`；颜色全走 CSS 变量；400px 不横向滚动；每个模块数据缺失显示"未取得数据"。
