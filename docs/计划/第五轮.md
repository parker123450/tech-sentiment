# 科技情绪全景 · 第五轮计划：真正能衡量的东西、看得懂的期权、免费自动部署

## 背景

你这次提了五件事：
1. 页面变黑了，要换回白色。
2. 每天的市场波动、情绪、隐含波动率都要能看到。
3. 期权的东西很多（偏度、大单……），看不懂，要讲清楚怎么看。
4. 每天自动运行，不靠 Claude，免费部署，手机和电脑都能看。
5. **最重要**：找出哪些东西真的能衡量涨跌，而不是为了打分。

已经核实的事实：
- **页面变黑**：模板跟随系统外观，你的 Mac 是深色外观。
- **能衡量什么**（只读测算，2015 年前后分开）：
  - **期权隐含波动率能预告之后一个月的波动幅度**。纳指 VXN 和之后 21 天实际波动的相关系数：2015 年前 0.86、2015 年后 0.62，比用过去的波动去推更准。对半导体要用科技或半导体自己的期权（标普 VIX 只有 0.5 左右）。
  - **价格在 200 日线下方时，风险明显更大**。25 个品种里，之后一个月的波动是上方的 1.2 到 1.4 倍；60 天内再跌 15% 的概率，2015 年前 38% 对 26%，2015 年后 29% 对 18%。八成以上的品种、两段都是这样。
  - **方向几乎测不出来**。200 日线上下，之后 60 天涨跌的中位数差不多，只有一半品种下方更差。

  结论：能可靠衡量的是**接下来波动多大、下跌风险多高**；能衡量方向的，只有之前验证过的"跌深 + 恐惧充分定价"等少数组合。
- **部署**：你选了 GitHub 公开仓库，盘中每 30 分钟加收盘后一次，手机推送用 ntfy。本机没有 GitHub 命令行工具，文件夹也还不是 git 仓库。

## 怎么做（按顺序，每步做完先给你看）

### 第 1 步：换回白色，先解决看不清的问题
- 默认白色，不再跟随系统。页头加一个"浅色 / 深色"切换按钮，记在浏览器里。
- 顺手把小字、灰字的对比度调高一点，手机上按钮和点击区域加大。

### 第 2 步：研究"真正能衡量的东西"
在 `research.py` 里按现有规矩先登记、再检验，结果只决定标签，不回头改阈值。检验在 33 个品种上做，分 2015 年前后。

| 编号 | 检验什么 | 衡量的是 |
|---|---|---|
| M1 | 期权给出的预期波动（隐含波动）对之后 21 天实际波动：相关系数；实际涨跌落在 ±1 倍预期波动内的比例 | 幅度 |
| M2 | 趋势状态（200 日线、50 日线上下，摆动结构）对之后一个月的波动和 60 天内再跌 15% 的概率 | 下跌风险 |
| M3 | 过去 21 天实际波动高低对之后的波动（波动会扎堆） | 幅度 |
| M4 | 同样这些状态对之后 60 天的涨跌（预计很弱，如实写出来） | 方向 |

标签改成三类：
- **能衡量幅度 / 风险**：两段都成立、多数品种成立。
- **能衡量方向（有历史支持）**：沿用原规则。
- **只作描述**：其余。

输出写进 `研究结论.md`、`规则说明.md`。

### 第 3 步：看板内容重排，先说"能衡量的"
1. **顶部"今天该知道的三件事"**：
   - **接下来可能波动多大**：用期权给出的预期范围。例如"SMH 未来一个月预期 ±10.7%、一周 ±5.1%"，同时给出英伟达、QQQ、韩国 ETF，并附历史命中率。
   - **下跌风险高不高**：趋势状态加波动状态，附历史上 60 天内再跌 15% 的概率。
   - **情绪走到哪一步**：保留现在的对照格和三个温度。
2. **"每日一览"表**：最近 20 到 60 个交易日，每天一行。
   - 列：半导体收盘和涨跌、当天波动、20 日实际波动、VIX、VXN、SMH 30 天隐含波动、三个温度、恐惧条数、脆弱条数。
   - 单元格按高低着色，点一行跳到 K 线那一天。这就是你要的"每天的波动、情绪、隐含波动都看得到"。
3. **K 线**：在最新一根右边画出期权给出的未来一个月预期范围（±1 倍和 ±2 倍）。
4. **期权部分改成"期权怎么看"**：五个白话问题，每个一句结论、一个颜色，加一行"为什么重要"（点开才看）：
   - 市场预期接下来波动多大？保险贵还是便宜？（隐含波动和实际波动比）
   - 有没有人在买下跌保护？（偏度、认沽/认购比，偏度的白话说法是"下跌保险比上涨期权贵多少"）
   - 担心的是眼前还是以后？（期限结构，标出财报日）
   - 大资金押在哪？（收盘后的持仓变化：新增最多的合约、到期日和行权价，用白话写）
   - 今天盘中谁在主动买卖？（云端每 30 分钟抓一次后才可靠，会标出数据质量）
5. 术语旁加 ⓘ 小提示；长历史数据按需加载，手机打开更快。

### 第 4 步：免费自动部署（GitHub 公开仓库 + 网页）
- **新增 `.github/workflows/update.yml`**：
  - 美股交易日盘中每 30 分钟跑一次，收盘后固定再跑一次（自动处理夏令时），也可以手动触发。
  - 每次跑完把看板发布到 `https://你的用户名.github.io/仓库名/`，手机和电脑同一个网址。
- **数据怎么存**：
  - 大的历史行情（约 33MB）放在 GitHub 的缓存里，丢了就重新下载。
  - 小而重要的文件每天收盘后提交到单独的 `data` 分支：样本外日志、认沽/认购比历史、期权快照、最近 10 天的持仓快照。
  - 这些每天的提交也让仓库保持活跃，GitHub 不会因为 60 天没动静而停掉定时任务。
- **期权主动买卖**：两次抓取间隔不超过 75 分钟都算正常（GitHub 定时常晚 5 到 30 分钟），超过就标"粗略"。
- **代码改动**：
  - `build_sentiment.py` 加一个输出网站文件的选项，不需要代理也能跑。
  - 通知在 Mac 上照旧弹桌面通知，在云端改发 ntfy。
- **需要你自己做的**（约 10 分钟，账号密码我不碰）：
  1. 注册或登录 GitHub，建一个公开仓库。
  2. 在 Mac 上登录 GitHub：装 GitHub Desktop，或者在终端里运行 `gh auth login`，登录由你自己完成。
  3. 在仓库设置里打开网页发布（Pages 选 "GitHub Actions"）。
  4. 在仓库设置里加一个秘密值 `NTFY_TOPIC`，值是我给你的随机频道名。
  5. 手机装 ntfy App，订阅同一个频道名。
- **云端跑通之后**：停掉 Claude 应用里的"每日更新手机网页"任务（省用量）；本机定时任务只保留桌面通知，或者停用，到时问你。
- **风险**：
  - Yahoo 可能限制云服务器的访问频率。已有兜底，会沿用上次的数据并在页头标出；第一次手动运行时就能看出来。
  - 页面和代码是公开的，内容只有公开行情和分析。

### 第 5 步：手机推送（ntfy）
推送的信号和现在桌面通知一样：恐惧充分定价、恐慌退潮、脆弱度 ≥ 4、VIX 倒挂、VIX 跳升、SOX 跌 4%、SMH 卖出高潮，每条附历史参考和网页链接。看板更新失败也推一条。
