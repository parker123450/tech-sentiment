# 科技情绪全景 · 第六轮计划：三个因子、周期位置、一屏看懂（2026-10-23 定稿）

讨论过程见 `docs/审查/2026-10-22_第六轮指标核对.md`、`docs/审查/2026-10-23_流动性利率和前瞻性.md`。用户定的方向：**第一屏默认是因子和情绪分，下面紧接 K 线，K 线上把情绪对上；其余折叠，看不懂的指标只要三句话说明。** 用户同意"去、改、留"清单，流动性放折叠的宏观背景。

## 一、衡量框架的改动（都登记在 `engine.py`）

### 去、改、留（用户 2026-10-23 同意）

| 动作 | 项目 | 理由（和检验结果无关的机制理由） |
|---|---|---|
| 去 | SKEW、VVIX、指数认沽/认购比 | SKEW 是尾部对冲需求，恐慌时整条曲面抬升反而下降，机制上不是恐惧指标；VVIX 是 VIX 自己的波动，和 VIX 同源；指数期权以机构对冲为主，和股票期权机制不同 |
| 并 | VXN 水平、VXN 跳升并进"大盘期权"组 → 定价恐慌只剩三组：大盘期权、期权成交、信用 | VXN 和 VIX 同源（都是指数期权），分两组等于给同一件事双倍权重；VXN 仍用于半导体隐含波动的折算（M1） |
| 改 | 抛售恐慌里的"KOSPI 20 日波动 ÷ 长期波动（1 → 2 倍）" → "KOSPI 20 日 Z 分数（0 → −2）" | 和项目里"速度"的统一口径一致（20 日涨跌 ÷ 长期日波动 × √20，≤ −2 急跌）；波动翻倍是崩盘级事件，和其他项"到公认的恐慌水平"不是一个量级 |
| 改 | "上涨变窄"：原来"离高点 3% 以内且成分股 50 日线上方 < 60%（或等权跑输 ≥ 2%）" → "离高点 5% 以内，且成分股 50 日线上方的比例比自己 60 日峰值回落 ≥ 20 个百分点（或等权跑输 ≥ 2%）"；温度里的连续版 0 → 30 个百分点 | 顶部的共同特征是"参与度先于价格见顶"，要衡量的是参与度**从峰值回落了多少**，不是它的绝对水平；5%、20 点、60 日是整数惯例。清单项改了，`research.py` 重跑，标签重打 |
| 留 | VIX、VIX 跳升、倒挂、认沽/认购（两种）、SOXL÷SOXS、Baa、HYG÷IEF、成分股 50 / 200 日线上方、新高减新低、RSI、20 日 Z、回撤、离 200 日线 | 核对里顶底命中高、互相不重复 |
| 不改 | 情绪分公式、分档；三个温度的结构；对照格；清单其余各条；离 200 日线 1 倍年化波动的刻度 | 连续版在顶部中位数读到 69，作为温度够用 |

情绪分照旧 = 过热 − (定价恐慌 + 抛售恐慌) ÷ 2，只是输入项按上面改了，所以数值和以前略有不同（口径变更日 2026-10-23，`daily_log.csv` 里之前的行保留当时的读数）。

### 三个因子（新，显示用）

同一批 0–1 项目按机制重分三组，各自平均，给第一屏看。温度是情绪分的输入，因子是人看的分组，两者用的是同一批项目。

| 因子 | 项目 | 读数 | 回答 |
|---|---|---|---|
| 波动恐惧 | VIX、VIX 跳升、倒挂、Baa 走阔、HYG÷IEF | 0 平静 → 100 恐慌 | 有没有人花钱为下跌买保险 |
| 仓位 | 恐惧侧：认沽/认购跳升、去杠杆；自满侧：认购狂热或杠杆 | −100 恐惧对冲 → +100 自满加杠杆 | 人群押在哪一边 |
| 价格与参与度 | 恐惧侧：成分股普跌、KOSPI 急跌；过热侧：延伸、顶背离、缩量新高、上涨变窄、价涨波动也涨 | −100 普跌 → +100 过热 | 价格走到哪一步、多少股票在跟 |

### 周期位置（新，只作描述）

把核对里重复出现的**顺序**写成状态，按先后判断，互斥：

| 状态 | 条件 | 来源 |
|---|---|---|
| 恐慌定价中 | 恐惧定价 ≥ 3 条 | 原清单 |
| 恐慌退潮 | 退潮确认四条 | 原规则 |
| 二次探底 | 过去 60 天出现过恐慌（≥ 3 条），今天价格创 20 日新低，但恐惧条数少于那次峰值 | 核对：磨底时最后的低点恐惧更少 |
| 跌了没人买保险 | 回调或重伤 × 恐惧 0 条 | 原对照格 |
| 跌了部分定价 | 回调或重伤 × 恐惧 1–2 条 | 原对照格 |
| 顶部结构 | 离高点 5% 以内，且参与度比 60 日峰值回落 ≥ 20 点；仓位自满项亮时加"仓位自满" | 核对：参与度先走、仓位自满 |
| 延伸 | 离 200 日线超过 1 倍年化波动 | 原价格位置 |
| 普涨回归 | 广度推力 | 原规则 |
| 平稳 | 其余 | |

每个状态显示：进入第几天；顺序线（参与度峰值、VIX 峰值、认沽/认购峰值、价格高点或低点各在几天前）；历史上处在这个状态之后 60 天的中位数和同深度对照（描述，不打标签）。

### 指标注册表（新）

每个显示的指标登记：属于哪个因子、名字、**是什么、代表什么情绪、有什么用**（三句话）、作用标签（能衡量幅度 / 能衡量风险 / 有历史支持 / 只作描述；前瞻 / 同步）、方向、刻度。看板的指标表、i 提示、说明页都从这里生成。

每个指标另算 **5 日变化在自己历史里的分位**（只用当天以前），≤ 2% 或 ≥ 98% 标"急"（沿用情绪分速度的 2% 惯例）。"今天动了什么"从这里来：灯新亮或熄灭、变化进了最快 2%。

### 宏观背景（新，折叠，只作背景）

净流动性（美联储总资产 − 国库账户 − 逆回购）、10 年国债、10 年 − 2 年、债券波动 MOVE、美元指数。画图、给分位，页上写明"检验过：对之后 20–60 天涨跌没有前瞻性"。不进任何判断。

## 二、看板（三层，默认只看第一层）

**第一层**
1. 情绪分：大数字、档位、5 天变化、一句白话；三个温度作为公式一行小字；合理区间和超出价格的恐慌收成一行。
2. 三个因子：三张卡，各一个读数、状态词、一句"现在"、今天变化；点开看该因子的指标表（名字、三句话、标签、今天、昨天、5 天前、分位、变化分位、灯）。
3. 周期位置：状态名、第几天、顺序线、历史对照；下面"今天动了什么"三到五条。
4. 两件能衡量的事：期权给的下月幅度、下跌风险档（原三件事去掉第三件，并入周期位置）。
5. K 线：副图新增"三个因子"；价格区底部新增"周期位置"色带（可切换情绪分色带）；情绪标签、期权预期范围、摆动结构照旧。

**第二层（点开）**：因子的指标表；对照格、清单、退潮确认、脆弱度（原总览的核心块）。

**第三层（折叠）**：每日一览、期权怎么看、参与度、宏观背景、历次对照、说明（含指标词典：每个指标三句话和标签）。

- 回填 `daily_log.csv` 的 `score` 列。
